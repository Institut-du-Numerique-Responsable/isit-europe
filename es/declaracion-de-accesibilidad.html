Declaración de accesibilidad

Inicio › Declaración de accesibilidad

ISIT Europe se compromete a hacer accesible su sitio web a todas las personas, incluidas las personas con discapacidad, conforme a las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1, nivel AA.

Esta declaración se aplica a isit-europe.org (y a sus versiones en EN / FR / DE / IT / ES).

Estado de conformidad

Este sitio se encuentra en un estado de conformidad parcial: el sitio sigue en gran medida las WCAG 2.1 AA, sobre la base de una autoevaluación interna (revisión manual del código: estructura semántica, contraste de color, navegación por teclado, textos alternativos, visibilidad del foco). No se ha realizado una auditoría externa formal según la parrilla completa de 106 criterios del RGAA; por tanto, no se reivindica ningún porcentaje de conformidad.

Contenidos no accesibles

Limitaciones conocidas

  • Algunos sitios de socios externos enlazados desde este sitio (organizaciones miembro, plataformas de proyectos) no están bajo nuestro control y podrían no alcanzar el mismo nivel de accesibilidad.
  • Aún no se ha registrado ninguna sesión formal de pruebas con tecnologías de asistencia (combinación lector de pantalla + navegador); la verificación se ha limitado a una revisión manual del código y del contraste.

Contenidos no sujetos a la obligación de accesibilidad

  • Ninguno identificado por el momento.

Elaboración de esta declaración

Esta declaración se elaboró el 23 de julio de 2026.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • Sin framework de JavaScript en el cliente - se usa una pequeña cantidad de JavaScript nativo únicamente para el panel de monitorización interno (no indexado).

Entorno de pruebas

Verificaciones realizadas manualmente en un navegador de escritorio actual (basado en Chromium), con cálculo automatizado de los ratios de contraste de color (fórmula WCAG 2.1) para todos los pares de color texto/fondo definidos en la hoja de estilos.

Páginas verificadas

  1. Página de inicio - isit-europe.org/es/ (y versiones EN, FR, DE, IT)
  2. Avisos legales & política de privacidad - /es/legal-notices.html (y versiones localizadas)
  3. Esta declaración de accesibilidad
