Accessibility Statement

Home › Accessibility Statement

ISIT Europe is committed to making its website accessible to everyone, including people with disabilities, in line with the Web Content Accessibility Guidelines (WCAG) 2.1, level AA.

This statement applies to isit-europe.org (and its EN / FR / DE / IT / ES language versions).

Conformance status

This website is in a partial conformance status: the site largely follows WCAG 2.1 AA, based on an internal self-assessment (manual code review - semantic structure, colour contrast, keyboard navigation, alternative text, focus visibility). A formal third-party audit against the full 106-criteria RGAA reference grid has not been carried out; no percentage compliance score is claimed.

Non-accessible content

Known limitations

  • Some external partner sites linked from this site (member organisations, project platforms) are outside our control and may not meet the same accessibility level.
  • No formal assistive-technology testing session (screen reader + browser combinations) has been logged yet; testing has been limited to manual code and contrast review.

Content not subject to the accessibility obligation

  • None identified at this time.

Establishment of this statement

This statement was drawn up on 23 July 2026.

Technologies used

  • HTML5
  • CSS3
  • No client-side JavaScript framework - a small amount of vanilla JS is used only for the (non-indexed) internal monitoring dashboard.

Test environment

Reviewed manually in a current desktop browser (Chromium-based), with automated colour-contrast ratio calculations (WCAG 2.1 formula) for all text/background colour pairs defined in the stylesheet.

Pages checked

  1. Home page - isit-europe.org/ (and /fr/, /de/, /it/, /es/)
  2. Legal notices & privacy policy - /legal-notices.html (and localised versions)
  3. This accessibility statement

Feedback and contact

If you are unable to access any content or feature on this site, contact us so we can provide an accessible alternative or the content in another format.
